Photopea did not load

PixOS serves every page with Cross-Origin-Embedder-Policy, and a COEP document may only embed frames that set COEP themselves. photopea.com does not, so the browser blocks it unless the frame below is marked credentialless — which only Chromium-based browsers understand.

In Firefox and Safari this app cannot work. Everything else in PixOS is unaffected; the attribute is on this one frame and changes nothing globally.
